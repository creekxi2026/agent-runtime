# Agent guidance

When asked to provision an Agent Runtime for a user, read
[docs/agent-setup.md](docs/agent-setup.md) first. It contains the parameter
questions, software proposal, user confirmation, Multica connection, and
verification workflow. Read it as task instructions; do not install it as a
skill or arrange a first-conversation hook.

Reading this repository alone does not authorize deployment. Follow the guide
only for a provisioning request, reuse information already supplied by the
user, and wait for approval of the concrete installation plan before mutations.
Ordinary code or documentation maintenance does not trigger provisioning.
